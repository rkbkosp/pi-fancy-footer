Configure JSON balance and quota APIs directly in fancy-footer.json. Declarative providers support active-provider matching, GET and JSON POST requests, environment-backed headers and bodies, deterministic selectors and numeric transforms, reset timestamps, native quota gauges, bounded requests, endpoint-aware caching, stale fallback, and secret-safe errors.
